## Layering check against docs/architecture/containers.md

`containers.md` declares a one-directional layering: UI (`tui`/`cli`) depends on Application/Provider (`llm`), which depends on Service (`services`), which depends on Database (`db`). An edge running the other way - `db`, `llm`, `services`, or `config` depending on `tui` - is that layering inverted.

None found - no lower-layer module depends on `tui`.
